# معالم السنة النبوية (صالح أحمد الشامي)

1. ملفات PDF المصوّرة في `data/raw/maalim/` (غير مرفوعة؛ الكتاب محفوظ الحقوق).
2. OCR بمكتبة Vision في macOS (العربية) → `data/raw/maalim/ocr_{1,2,3}.txt`.
3. `python3 pipeline/maalim/parse_maalim.py` → `data/raw/maalim/maalim.json`
   (حديث لكل عنصر: n، المجلد والصفحة، المقصد/الكتاب/الفصل/الباب، الرمز ق/خ/م،
   النص، الإحالات المحللة، الحكم) و`maalim_pages.json` (حواشي كل صفحة).

الترقيم كما طُبع: `n` الرقم، و`label` بلاحقة «م» إن وُجدت (١٢٤٦م، ١٥٨٢م…)،
و`dup_number` للرقم المطبوع مرتين (١١٢٤، ١٥٨١)، و`empty` لرقم نبّه المؤلف أنه
«سقط سهوًا ولا حديث تحته» (٢٠٨١، وكذا ١٩١١ في الحاشية). ولا وجود في الطبعة
للرقمين ١١٢٥ و١٥٨٣. و`seq` ترتيب متسلسل.

الصفحات التي أُعيدت قراءتها بدقة أعلى (لسطور أسقطها OCR) تُوضع في
`data/raw/maalim/ocr_fix/v{vol}_p{page}.txt` فتحل محل صفحتها.

قيود معروفة: بعض السطور يسقطها OCR، والحواشي محفوظة لكل صفحة لا لكل حديث.

## الربط ببرنامج «الجامع»
`python3 pipeline/maalim/link_maalim.py` → `data/raw/maalim/maalim_links.json`
و`maalim_links_review.tsv` (ما لم يُحسم، للمراجعة).

نص OCR للمطابقة فقط؛ المخزَّن لكل حديث `primary` = مفتاح حديث «الجامع» (b…، m…،
ibnhibban:…، mustadrak:…، bayhaqi:…)، و`links` لكل إحالة مع طريقة المطابقة ودرجتها:
- `number`: الرقم نفسه (الستة والدارمي وابن حبان وابن خزيمة توافق ترقيم «الجامع»)،
  و`number±k`/`number-ocr` لأرقام شوّهها OCR، و`number-weak` للرقم نفسه بدرجة متوسطة.
- `text`: بحث بالنص في الكتاب المحال إليه (أحمد بترقيم الرسالة، والموطأ، والمستدرك،
  والمختارة، والبيهقي بالجزء والصفحة)، بشرط اسم الصحابي في نص «الجامع».
- `text-global`: لا إحالة مقروءة؛ بحث في الكتب كلها بدرجة 0.6 فأكثر.
